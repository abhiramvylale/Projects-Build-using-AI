📶 Connect Your Machine to Wi-Fi

Follow these 3 quick steps to establish the initial Wi-Fi connection for your assigned controller (AQ-ESP32-001):

Step 1 — Power On Your AquaSmart Unit
Plug your ESP32-C3 controller into a USB/5V power adapter. If it is already connected to another Wi-Fi, hold the BOOT button (GPIO 9) for 5 seconds.
Step 2 — Connect to the Setup Hotspot
On this phone or computer, open Wi-Fi settings and connect to the network named AquaSmart-Setup.
Step 3 — Open the Machine Setup Screen
Click the button below while connected to AquaSmart-Setup. It will pre-fill your assigned Machine ID and Cloud Database URL automatically:
Open Machine Setup Page (192.168.4.1) ↗
